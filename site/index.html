Everything you open a text editor for.

Open a file, fix it, close it. Nimble Newt keeps the familiar Notepad++ workflow and takes care of the parts that usually go wrong: lost tabs, broken encodings, careless saves.

Quit any time. Your tabs come back.

Unsaved tabs survive quitting and restarting, including the ones you never named. Their content lives in the app’s data folder, never next to your files, and the cursor and scroll position come back with them.

Open as many tabs as you like, drag them into order, close others or everything to the right, and bring a closed one back with Ctrl Shift T. Prefer a clean slate? Switch session restore off in Settings.

Every byte where you left it.

Nimble Newt detects UTF-8 with or without a BOM, UTF-16 LE and BE, and Windows-1252, and shows it in the status bar. Click it to convert the file, or to reopen it with another encoding. LF, CRLF and CR work the same way.

Characters the target encoding can’t represent are reported, never silently lost.

Find it in one file, or a whole folder.

Find and replace in the file you’re in, with regular expressions, case and whole-word options and a live match count.

Find in Files searches a folder with regex and glob filters, respects .gitignore, skips binary files and gives you clickable results. Replace All shows a preview first, and you can leave out any file before anything is written.

And the rest of a proper editor.

Every action is also in the command palette. On a Mac, read Ctrl as ⌘.

  • Syntax highlighting

    23 languages, picked from the file name or shebang and switchable from the status bar. Colours meet WCAG AA contrast.

  • Multiple cursors and columns

    Ctrl+click, Ctrl D for the next occurrence, Alt+drag for a column. Duplicate, move and comment lines, fold code, wrap words.

  • Command palette and quick open

    Ctrl Shift P runs any action by name. Ctrl P jumps to a recent file.

  • A status bar you can click

    Line and column, selection, indentation, language, encoding and line endings. Click any of them to change it.

  • Saves you can trust

    Atomic saves, so a crash never truncates a file. If another program changed it, you’re asked before anything is overwritten.

  • Updates that check themselves

    A small pill in the status bar when a new version is out. Every download is verified against a key built into the app, and your tabs come back after the restart.

  • Opens the way you do

    From the menu, by drag and drop, with “Open with…”, or as the default app for text, Markdown, data and source files.

  • Settings, in English or Norwegian

    System, light or dark theme, font size, tabs or spaces, default encoding and line ending, word wrap and whitespace. The interface speaks English and Norwegian Bokmål.

  • Accessible by default

    Keyboard navigation everywhere, visible focus, and respect for reduced motion, higher contrast and reduced transparency.

Nimble Newt and Notepad++.

Notepad++ is a superb, mature editor with twenty years of features and a big plugin community, and Nimble Newt borrows its spirit. Here’s an honest comparison.

When Notepad++ is the better fit If you rely on plugins or macros, open files of several hundred megabytes, or need an encoding or language beyond the ones above, Notepad++ is the better choice today. If you want the same quick editing on a Mac, or a calmer, modern interface on Windows, give Nimble Newt a try. Nimble Newt is not affiliated with Notepad++.

Download Nimble Newt.

Free, for Windows and macOS. The latest version is always on the GitHub releases page.

Nimble Newt is a desktop app It runs on Windows and macOS computers, not on phones or tablets. Open this page on your computer to download it.

  • Windows

    For this computer

    Windows 10 or 11, 64-bit (x64). Uses Microsoft Edge WebView2, which comes with Windows 11; on Windows 10 the installer fetches it if it’s missing.

    Download .exe Download .msi

    The .exe installer suits most people; the .msi is for managed deployments.

    Windows will warn you the first time The Windows build isn’t code-signed yet, so SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway. Updates are still verified with the app’s own signing key.

  • macOS

    For this Mac

    macOS 11 Big Sur or later. One universal app for both Apple Silicon and Intel Macs.

    Download .dmg

    Open the disk image and drag Nimble Newt to Applications.

    Signed and notarized The Mac app is signed with an Apple Developer ID and notarized by Apple, so macOS opens it without the unidentified-developer warning.

Already installed? Nimble Newt updates itself. It checks GitHub at start and every six hours, and you can turn that off in Settings.

Questions.

  • Is it really free?

    Yes. Nimble Newt is open source under the MIT license, with no account, ads or paid tier. The code is on GitHub.

  • Why does Windows say “Windows protected your PC”?

    The Windows installer isn’t signed with a code-signing certificate yet, and SmartScreen warns about unsigned apps it hasn’t seen often. Click More info, then Run anyway. The Mac build is signed and notarized.

    Updates are a separate matter: every update is checked against a public key built into the app, and one with a wrong or missing signature is never installed.

  • Does it collect any data?

    No. There’s no telemetry or analytics. The only network request is the update check, which downloads a small file from GitHub at start and every six hours. You can turn it off in Settings → Updates and use Check for Updates… by hand.

  • Where are my unsaved tabs kept?

    In the app’s own data folder on your computer, never next to your files. If you’d rather be asked about unsaved changes when you quit, switch off Restore session in Settings.

  • Can it open very large files?

    Files up to 256 MB open in the editor. Bigger ones are refused with a clear message for now; viewing files of 500 MB and more, streamed in chunks, is on the roadmap.

  • Is there a Linux version?

    Not as a download. Releases are made for Windows and macOS, but the app builds and runs on Linux from source (the screenshot on this page comes from a Linux build). See Build from source.

  • What’s coming next?

    On the roadmap: large-file viewing, comparing two files, formatting JSON, XML and SQL, a tools panel (Base64, URL encoding, hashes), and extensions.

  • Can I translate it into my language?

    Please do. The interface text lives in one JSON file per language; copy the English one and translate the values. The translation guide has the details.
